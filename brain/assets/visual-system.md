# Recognizable character

Superseller is a calm operations product for marketplace sellers. It should feel practical, controlled, trustworthy, and warm rather than playful or futuristic.

# Core palette

| Role | Value |
| --- | --- |
| Canvas | `#FBFBFB` |
| Panel | `#FFFFFF` |
| Inset | `#F4F3F3` |
| Border | `#E3E2E1` |
| Heading | `#171717` |
| Body | `#41403F` |
| Supporting copy | `#535251` |
| Primary orange | `#BF4919` |
| Orange accent | `#A83D0F` |
| Orange strong | `#8A320E` |
| Light action text | `#FEFEFE` |

Use orange for the primary action or one meaningful emphasis, not as decoration on every element.

# Typography

- Typeface: Inter.
- Weights: 400, 500, 600, and 700.
- Sentence case for normal text.
- Uppercase only for small category labels or badges.
- Social assets may use roughly 30–40 px section headlines, 38–48 px major CTA text, and up to 60 px hero text when the composition supports it.

# Composition

- Off-white canvas and white panels.
- Warm charcoal text.
- Mild corner radii.
- Restrained borders and quiet shadows.
- One clear visual hierarchy.
- Marketplace work, human control, product knowledge, and automation boundaries.
- Adapt the system to social media rather than imitating an app screenshot.

# Avoid

- Neon or purple-first AI branding.
- Glassmorphism, inflated controls, and heavy shadows.
- Robot, brain, or magic imagery.
- Decorative dashboard metrics.
- Multiple competing calls to action.
- Synthetic customer proof.

# Graphic generation rule

Prefer deterministic brand layouts for typography, logo placement, and claims. Generative imagery may supply a supporting illustration, but it must not alter the logo, invent UI, fabricate people, or introduce unsupported product claims.
