# Supported capability set

Superseller can:

- Connect an Allegro seller account.
- Synchronize active offers.
- Prepare product knowledge from offer descriptions and parameters.
- Combine general shop knowledge with offer-specific knowledge.
- Apply seller-defined rules before generated wording.
- Let the seller choose automatic replies or editable suggestions.
- Learn reusable preferences from meaningful seller edits.
- Test replies and handoffs before activating automation.
- Escalate unsupported, low-confidence, complaint-related, or human-requested cases.
- Show rules, supporting sources, confidence, and outcomes.
- Send post-purchase messages with order variables.
- Create offer-specific post-purchase variants where supported by the plan.
- Track used and remaining AI replies.

# External-use boundary

Use this list as capability truth, not as evidence of performance. Do not infer exact time savings, automation rate, reply speed, customer adoption, or return on investment.

Avoid exposing implementation details unless the campaign is explicitly about engineering.
